## 🚀 Un lugar para entrar en modo enfoque

FOCUS reúne las herramientas cotidianas en una interfaz personalizable: abre tus recursos, organiza tu jornada y mantén el ritmo sin saltar entre mil ventanas.

| Módulo | Para qué sirve |
| --- | --- |
| **Accesos y carpetas** | Guarda enlaces y agrúpalos para encontrarlos al instante. |
| **Pomodoro** | Divide el trabajo en sesiones enfocadas y descansos. |
| **Tablero Kanban** | Convierte pendientes en un flujo de trabajo visual. |

## ⬇️ Instalar en Windows

1. Descarga el [instalador más reciente](https://github.com/DFelipeR/Focus-A.A/releases/latest).
2. Ejecuta `Focus_0.1.0_x64-setup.exe`.
3. Sigue el asistente y abre FOCUS.

También puedes visitar la [página de releases](https://github.com/DFelipeR/Focus-A.A/releases) para consultar otras versiones.

## 🛠️ Ejecutar desde el código

Necesitas Node.js, pnpm, Rust y las herramientas de compilación de Windows requeridas por Tauri.

```powershell
pnpm install
pnpm exec tauri dev
```

Para generar el instalador NSIS:

```powershell
pnpm exec tauri build --bundles nsis
```

El resultado se guarda en:

```text
src-tauri/target/release/bundle/nsis/
```
